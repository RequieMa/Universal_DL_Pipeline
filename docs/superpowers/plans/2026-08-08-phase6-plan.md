### Task 1: TextDataSource + SimpleTokenizer

**Files:** `pipeline/data/text_source.py`, `pipeline/data/tokenizer.py`, `tests/unit/test_text_source.py`, `tests/unit/test_tokenizer.py`

TextDataSource follows CsvDataSource pattern exactly: lazy _load(), batch_size+shuffle+seed, __len__ returns batch count. Batch(inputs=list[str], targets=np.ndarray).

SimpleTokenizer: fit(texts) builds vocab dict, encode(text) returns list[int], decode(tokens) returns str, vocab_size property. Handles OOV via <UNK> token.

Tests: 8+ TextDataSource (construction, len, iter yields strings, shuffle, empty, vocab collection) + 8+ Tokenizer (fit vocab_size, encode/decode round-trip, oov, min_freq, max_vocab truncation, empty text, special tokens).

Commit: `git commit -m "feat: add TextDataSource + SimpleTokenizer"`

### Task 2: M5 IMDB sentiment notebook

**Files:** `examples/m5-text-imdb/imdb.ipynb`

LSTM model: Embedding(vocab_size, 128) → LSTM(128, 64, batch_first=True) → Linear(64, 1) → Sigmoid. Use torchtext.datasets.IMDB or download from torchvision. Train with TorchAdapter, target >85% val accuracy. Plot loss curve.
